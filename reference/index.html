推荐阅读顺序#

如果你要快速入门：07 → 05 → 01（理解 Repo RAG 的基础概念和演进）

如果你要构建生产系统：01 → 08 → 03 → 06（检索路由 + 评测 + 图索引 + KG问答）

如果你要支持代码变更辅助：02 → 03 → 10（规划 + 图导航 + 图集成模型）

如果你要建立评测体系：08 → 09（三层评测 + 长上下文评测）

如果你关注最前沿方向：10 → 03 → 06（图集成LLM + 图检索 + KG协同）
